# 数学建模竞赛全流程

主线七步：**审题 → 假设 → 建模 → 求解 → 灵敏度分析 → 写作 → 图表**。
不要一上来写代码，先把题读懂、把假设写清。

## 0. 先分清是哪个赛

- **CUMCM 全国大学生数学建模竞赛**：一般 3 天，题目 A/B/C 三类，中文论文
- **MCM/ICM 美国大学生数学建模竞赛**：一般 4 天，题目 A–F，英文论文（MCM 偏连续/离散/数据，ICM 偏环境/政策）
- 先确认赛制与语言，再决定用中文还是英文模板、按什么节奏写

## 1. 审题

- 逐句拆题干，列出**所有**要回答的问题，标清「问什么、求什么、给什么数据」
- 把数据文件先看一遍：维度、单位、缺失值、异常值；不要假设字段含义
- 找出题目的隐含约束（资源上限、时间、物理可行性）
- 产出：一页纸的问题重述 + 已知 / 未知清单，让用户确认理解无误

## 2. 假设

假设是评委重点看的部分，必须写清「为什么可以这么假设」：

- 每条假设对应一个简化理由，并说明它影响哪一步
- 假设要可检验；不能既假设 A 又要结论支持 A 的反面
- 数据缺失、忽略的次要因素单独列出
- 常见错误：假设与模型脱节（模型里用到的量在假设里没交代）

## 3. 建模

先定问题类型再选方法：

- 优化类 → 规划模型（目标函数 + 约束）
- 预测类 → 回归 / 时序 / 机器学习
- 评价类 → 层次分析、熵权法、TOPSIS
- 分类/决策类 → 判别、聚类、整数规划
- 机理类 → 微分方程、物理守恒
- 概率类 → 随机过程、蒙特卡洛

论文中要给全：符号表、目标函数、约束条件、变量取值范围。

## 4. 求解器选型（核心对照表）

按问题类型选库，别用错工具：

| 问题类型 | 库 | 备注 |
|---|---|---|
| 线性 / 整数规划 | `pulp` | 建模层，走 CBC/GLPK 开源求解器 |
| 凸优化 | `cvxpy` | 建模层，需装求解器后端 |
| 非线性 / 全局优化、插值、ODE | `scipy.optimize` / `scipy.integrate` | 通用首选 |
| 启发式 / 遗传算法 | `scikit-opt`（`import sko`）、`deap` | sko 有现成 GA/PSO；deap 适合自定义进化 |
| 多目标优化 | `pymoo` | Pareto 前沿、NSGA-II |
| 图论 / 最短路 / 网络流 | `networkx` | 建模与求解一体 |
| 统计检验 / 时序预测 | `statsmodels` | 检验、ARIMA 等 |
| 机器学习拟合 / 分类 | `scikit-learn`（`import sklearn`） | 回归、分类、聚类 |

⚠️ 提醒：

- `pulp` / `cvxpy` 只是**建模层**，真正求解要靠后端求解器
- **Gurobi / CPLEX 等商业求解器需要 license**，别默认用户有
- 默认开源求解器（CBC/GLPK）够用，但**大规模问题会很慢**，先小规模验证再上规模
- 启发式算法（GA/PSO）要设随机种子、多跑几次看稳定性，别只报一次最优值

## 5. 灵敏度分析（评委重点看）

目的：说明结论对参数扰动**稳不稳**，不是走过场。

- 选 2–3 个关键参数，各扰动 ±5% / ±10% / ±20%
- 记录目标值变化，画成曲线或表
- 结论：哪个参数最敏感、在什么范围内结论不变、超出范围会怎样
- 也可以对假设本身做扰动（换分布、去掉一条次要因素）
- 只报「结果稳定」却没有扰动数据 = 没做

## 6. 写作

- 结构：摘要 → 问题重述 → 假设 → 符号说明 → 模型建立与求解 → 灵敏度/检验 → 模型评价 → 参考文献 → 附录（代码）
- **摘要最关键**，评委先看摘要：方法、结果、结论要具体，给数字
- 模型与问题一一对应，每个问题都要有对应的求解与结果
- 结果要有**检验**（残差、误差、与实际或常识对照），不能只有「算出来了」
- 附录放完整代码，正文放关键片段

## 7. 论文模板

- 国赛：`latexstudio/CUMCMThesis`（国赛 cls，2025 年仍更新）
- 美赛：CTAN 的 `mcmthesis`（v6.3.x）
- ⚠️ 两个模板都需要 **XeLaTeX + 中文字体**；MacTeX 超过 1GB，优先让用户用 `tectonic`（约 50MB）
- 编译用 XeLaTeX，不要用 pdfLaTeX，否则中文字体报错

## 8. 图表

出图规范见 `academic-figures` 技能。要点：

- 矢量优先，导出 PDF
- 每张图要有编号、标题、坐标轴单位
- 流程图、模型结构图要画，别只堆公式
- 图注放图下方，表注放表上方

## 9. 常见扣分点

- 假设不合理或没写理由
- 模型与问题脱节，题目问的没答全
- 没有模型检验 / 灵敏度分析
- 图表不规范（无单位、无编号、位图糊）
- 摘要空泛、没有具体数字
- 代码不可复现（没给种子、没给数据来源）

## 10. 三天时间切分（参考）

- **D1**：审题 + 假设 + 定模型框架 + 数据清洗
- **D2**：编码求解 + 灵敏度分析 + 出图
- **D3**：写作 + 摘要打磨 + 交叉检查编号与引用 + 编译成稿
