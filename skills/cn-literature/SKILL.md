# 中文文献合规检索

核心：**只能在合规边界内做**。先讲红线，再讲能做什么。

## 1. 红线（绝不能做）

- **绝不允许**：绕付费墙、破解、批量爬取、共享账号 —— 这是**法律和合规红线**
- 不代替用户登录、不模拟机构账号、不伪造 IP
- 不做大规模自动抓取（违反目标站点条款，可能违法）
- 遇到需要授权的库，**引导用户用自己的合法渠道访问**，而不是 AI 去抓

## 2. 可用（开放 / 半开放）渠道

- **arXiv**：理工科预印本，配合已有 MCP 使用
- **Semantic Scholar**：跨学科，有 MCP；可拿引用数、参考文献
- **ChinaXiv**（chinaxiv.org）：中科院预印本平台，开放可检索
- **中国科技论文在线**（paper.edu.cn）：开放论文库
- **国家哲学社会科学文献中心**（ncpssd.cn）：人文社科开放资源；⚠️ 有面向机构 / API 用户的入口，但**公开文档未核实**，是否对个人开放**需进一步确认**，先确认再操作
- **万方开放平台**（apps.wanfangdata.com.cn/open/market/apis）：提供 API，但**需 app 认证与审核**，不是申请即用

## 3. 不可用 / 不能做

- **CNKI（知网）没有公开自助接入的开放接口**，其检索 API 按 **IP / 机构授权**，个人拿不到
- 所以**不要让 AI 去「自动查知网」**，技术上做不到，合规上也不允许
- 维普、万方主站同理：走机构授权，不能自动抓

## 4. 合规路径（推荐做法）

- 引导用户通过**学校图书馆入口**访问：校内 IP、VPN、图书馆账号，这是正当途径
- AI 的正确姿势：**给出检索式，让用户自己去库里查**，而不是替用户抓取
- 用户拿到结果（导出文件 / 题录）后，AI 再帮忙整理、去重、转格式
- 明确告诉用户「这一步要你自己在图书馆入口操作」，不要含糊带过

## 5. AI 能帮的部分

### 5.1 检索式构造

先跟用户确认三件事：**主题词、限定条件（年份/类型/语种）、要中文还是英文库**。

- 关键词组合 + 布尔逻辑：`(主题 A OR 同义词 A) AND (主题 B)`
- 同义词扩展：如 `"大语言模型" OR "LLM" OR "预训练语言模型"`
- 排除词用 `NOT`，缩小范围用 `AND`，扩大范围用 `OR`
- 限定：年份区间、文献类型（期刊/学位论文/会议）、语种、学科分类
- 截词与精确匹配：英文可用 `*` 截词，短语加英文引号精确匹配
- 中英文关键词互译，帮用户在英文库也能查

给出检索式后，说明**每条算式的意图**（哪条收紧、哪条放宽），并给用户 2–3 组备选。

### 5.2 检索结果整理

- 把用户导出的题录整理成清单：标题、作者、年份、出处、DOI（有则填）
- 按主题 / 年份 / 类型分组，标注与用户选题的相关度
- 去重：判定顺序 DOI > 标题+年份 > 标题
- 转格式：知网导出 **EndNote / RefWorks** 格式后，可转成 BibTeX（见 `citation-management`）
- 缺字段的条目单独列出，提示用户回原文补，**不要替用户编**

## 6. 常见坑

- 承诺「自动抓知网」 → 技术上做不到、合规上不允许
- 用开放平台 API 前没确认认证与审核要求 → 实际调不通
- 把 ncpssd 的 API 入口当成对个人开放 → 文档未核实，**先确认再操作**
- 批量爬取中文库 → 触碰红线
- 把检索式直接当结论给用户，却没说明怎么用 → 用户不知去哪查
- 中英文术语没对齐 → 中文库和英文库查出来的结果对不上
