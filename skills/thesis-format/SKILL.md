# 学位论文排版

核心思路：**用学校官方模板当样式源**，而不是手动一项项调格式。

## 0. 先问清楚两件事

1. 学校收 **Word** 还是 **LaTeX**？**多数学校只收 Word**，LaTeX 路线必须先确认学校接受
2. 有没有官方模板文件（`.docx` / `.dotx` / `.cls`）？没有就找学院要，别自己造

## 1. 主路线：pandoc + reference-doc

`pandoc --reference-doc=<学校模板.docx>` 会把模板的**样式定义**（标题层级、正文、页眉页脚样式）套到生成的 docx 上。这是最落地的做法。

完整命令：

```bash
pandoc thesis.md -o thesis.docx \
  --reference-doc=模板.docx \
  --citeproc --bibliography=refs.bib --csl=gb.csl
```

- 正文用 Markdown 写（或 Word 写初稿后再转）
- `--citeproc`：走 pandoc 内置的引用处理
- `--csl=gb.csl`：指定 GB/T 7714 样式（见 `citation-management`）
- 模板里的 **标题 1/2/3、正文、图注、表注**样式名要对上 Markdown 的 `#` / `##` / `###`

## 2. ⚠️ pandoc 做不到的事（必须手动收尾）

**不要承诺「全自动排版」。** 以下是真实限制：

- **目录**：pandoc 生成的目录**不是 Word 域**，**不会自动更新页码**。必须在 Word 里删掉，用「引用 → 目录 → 自动目录」重建
- **页码 / 页眉页脚**：套样式后仍要在 Word 里检查分节、奇偶页、起始页码
- **交叉引用**：pandoc 对「见图 3」「见式 (2)」的**交叉引用能力很弱**，编号往往靠手写，改了内容要人工核对
- **公式编号**：pandoc 不自动编号公式，需手动或后处理
- **题注**：图表题注要靠 Word 的「题注」功能，pandoc 只生成普通段落

所以交付时必须给用户一份**手动收尾清单**（见第 4 节）。

## 3. LaTeX 路线（中文学位论文模板）

真实仓库：

- 清华：`tuna/thuthesis`
- 华科：`hust-latex/hustthesis`

- ⚠️ 多数学校只收 Word，选 LaTeX 前**先确认学校接受**，否则白做
- 这两个模板一般用 XeLaTeX 编译，需要配中文字体
- LaTeX 路线的交叉引用、编号、目录自动生成，比 Word 省心；但学校不认就白费

## 4. 必须手动核对的清单

排版完逐项过一遍：

- [ ] 章节编号格式（`1` / `1.1` / `1.1.1` 还是 `第一章` / `1.1`），与模板一致
- [ ] 页眉：奇偶页内容、章节名是否自动跟随
- [ ] 页脚 / 页码：位置、起始页、罗马数字与阿拉伯数字的切换（摘要常要求罗马、正文阿拉伯）
- [ ] 公式编号：连续编号还是分章编号（`(2-1)` / `(2.1)`），全文一致
- [ ] 图编号、表编号：与正文引用一一对应，插入新图表后重新核对
- [ ] 目录：页码与实际一致（**每次改内容都要更新目录**）
- [ ] 参考文献序号与正文引用一致
- [ ] 摘要、关键词、致谢、附录的格式（字数、字体、是否单独成页）
- [ ] 字体：正文与标题的中西文字体（宋体 / 黑体、Times New Roman）符合模板
- [ ] 行距、页边距、装订线

## 5. 常见坑

- 目录页码不更新 → 打印出来对不上（最常见）
- 图表题注用了普通段落，Word 无法自动编号
- 分节符用错，导致页眉页脚串页
- 参考文献用 Word 手动敲，序号一增删就全乱 → 用 `--citeproc` 或 Zotero 插件管理
- 模板样式名不对，pandoc 静默套不上，格式没变却不报错
- ⚠️ **不要用「论文抽屉」「排版助手」这类工具** —— 付费闭源且 Windows-only，跨平台不可行，也无法接入自动化流程

## 6. 交付前自检

- 在 Word 里打开生成的 docx，确认样式确实套上了（不是默认 Calibri）
- 更新一次目录，确认页码正确
- 通读第 4 节清单
- 明确告诉用户哪些是自动的、哪些还要他自己动手
