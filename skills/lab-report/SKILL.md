## 2. 误差传递：uncertainties

pip 包名 `uncertainties`，用 `ufloat` 构造带不确定度的量，运算时**自动传播误差**。

```python
from uncertainties import ufloat
from uncertainties import umath

# ufloat(标称值, 标准不确定度)
l = ufloat(1.234, 0.005)      # 长度 (m)
t = ufloat(2.50, 0.02)        # 时间 (s)

v = l / t                      # 相除，不确定度自动传播
print(v)                       # 形如 0.4936+/-0.0045
print(f"{v:.3uS}")             # 按有效数字格式化输出

# 三角函数 / 对数 / 开方等：用 umath，而非 math
w = 2 * umath.pi              # ufloat 参与时用 umath
```

要点：

- 用 `ufloat` 后**普通 + - * / 会自动传播**，不用手写误差公式
- 三角函数 / 对数 / 开方用 **`umath`**，直接 `math` 不支持 ufloat
- `{x:.3uS}` 按有效数字输出（`u` 管不确定度、`S` 是科学记数样式），具体格式串可再微调

## 3. 曲线拟合：scipy curve_fit

```python
import numpy as np
from scipy.optimize import curve_fit

def model(x, a, b):
    return a * np.exp(-b * x)

x = np.array([...]); y = np.array([...])
popt, pcov = curve_fit(model, x, y, p0=[1.0, 0.5])

# 参数误差 = 协方差矩阵对角线的平方根
perr = np.sqrt(np.diag(pcov))
for name, v, e in zip(["a", "b"], popt, perr):
    print(f"{name} = {v:.4g} ± {e:.1g}")
```

要点：

- `pcov` 是**协方差矩阵**，**参数标准误差 = `np.sqrt(np.diag(pcov))`**
- `p0` 给初始猜测，**能显著提高收敛成功率**，尤其指数 / 多参数模型
- 有已知 y 误差时传 `sigma=yerr, absolute_sigma=True`，误差估计才更可信
- 拟合优度可算 `R²`，或看残差图，别只看参数值

## 4. 画误差棒图：matplotlib errorbar

```python
import matplotlib.pyplot as plt

plt.errorbar(x, y, yerr=dy, xerr=dx, fmt="o", capsize=3, label="测量值")
plt.xlabel("电压 $U$ / V")          # 名称带单位；量符号斜体
plt.ylabel("电流 $I$ / A")
plt.legend(); plt.grid(True)
plt.savefig("plot.png", dpi=150, bbox_inches="tight")
```

要点（图表规范）：

- **坐标轴名称必须带单位**：写成「物理量 / 单位」，如 `电压 U / V`
- **量符号斜体**（用 `$U$`），**单位正体**
- **图注（caption）放在图下方**，编号并写清是什么图
- 数据点用散点 + 误差棒，拟合曲线用 `plt.plot` 叠加，用图例区分

## 5. 有效数字与修约

- **不确定度取 1~2 位有效数字**（一般取 2 位，首位是 1 时可保留 2 位）
- **测量值末位与不确定度末位对齐**：如 `(1.234 ± 0.005) m`，不能写 `1.2345 ± 0.005`
- **中间计算多留 1~2 位**，最后一步再修约，避免累积误差
- 修约用「**四舍六入五成双**」（银行家舍入），不是简单四舍五入
- 加减法看**绝对误差**末位对齐；乘除法看**相对误差**（有效数字位数）

## 6. 误差来源分析（分类）

| 类型 | 特征 | 识别与处理 |
|---|---|---|
| **系统误差** | 单向、可重复，多次测量仍偏同一方向 | 来自仪器零点、方法/公式近似、环境影响；用**校准、改进方法、加修正值**减小 |
| **随机误差** | 时大时小、正负都有，服从统计分布 | 来自读数波动、环境起伏；用**多次测量取平均**减小，可用标准差估计 |
| **粗大误差** | 个别值明显偏离 | 来自读错、记错、操作失误；用 **3σ 准则 / 格拉布斯准则**判断后**剔除**，并说明依据 |

写报告要**具体点名**本实验可能的误差来源，而不是套话罗列。
