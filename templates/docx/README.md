# templates/docx/ —— 3 个可用的中文 .docx 模板（docxtpl 变量填充）

这里放 `skills/office-docs` 技能用的**模板库**：3 个已经把字体/行距/页边距/页眉页脚/目录域/三线表**预先做进样式**的 `.docx`。程序只做变量填充，不逐段调格式 —— 这就是「模板优先」的全部意义。

> **模板是用脚本生成的，不是手工做的二进制。**
> 生成器：`scripts/make_templates.py`（幂等，重复运行覆盖生成）。要改字号/版心/边框，改脚本常量重跑即可；`.docx` 也能在代码里被完整审计。**请勿手工编辑后忘记同步脚本**，否则改天重跑会被覆盖。

三个模板：

| 文件 | 用途 |
|---|---|
| `report-zh.docx` | 通用中文报告（实验报告 / 课程报告） |
| `gongwen-zh.docx` | 党政机关公文（GB/T 9704—2012） |
| `thesis-zh.docx` | 学位论文（各校共性要求） |

填充用 [docxtpl](https://pypi.org/project/docxtpl/)（基于 python-docx + Jinja2）。模板里的 `{{ ... }}` / `{%tr ... %}` 是 Jinja2 占位符。

## ⚠️ 先读：3 条共同的硬限制

1. **字体嵌入做不到。** python-docx 不支持写入 `w:embedRegular`，字体没法打进 .docx。两条路：① 在自己的 Word 里打开模板 → 文件 → 选项 → 保存 → 勾选「将字体嵌入文件」→ 另存后再当模板用；② **直接交付 PDF**（PDF 自控字形，不受对方机器缺字体影响，最稳）。
2. **目录域不会自动更新。** 目录是 Word 的**域**，程序写完不会算出来。打开文档后把光标放进目录区按 **F9**（或右键「更新域」→「更新整个目录」）才会生成。
3. **`仿宋_GB2312` / `楷体_GB2312` 不是系统标配字体。** 缺这些字体的机器（尤其非 Windows、未装 GB 字库）里会**静默回落**成别的字体。公文正式交付建议转 PDF。

另外：

- **占位符必须一次输入完整** —— `{{ title }}` 要一口气打完，不要中途改字号/加粗/换格式。Word 会把变过格式的文字拆进多个 run，docxtpl 就认不出占位符导致渲染失败。本仓库的模板是用 `add_run()` 一次性写入的（已保证是单个 run）；**风险主要在你手工改模板时**。
- **中文到底有没有回落，程序无法自证** —— 只能渲染成图目检（见 `SKILL.md` 第 3 节的渲染-目检循环）。本次生成环境未安装 LibreOffice，**未做渲染目检**，请在使用方机器上补做。
- **表格行循环**用 docxtpl 的 `{%tr %}` 语法：模板里有一行 `{%tr for ... %}`、一行数据样本、一行 `{%tr endfor %}`。渲染时两个控件行会被**整行删除**，样本行按数据条数重复。**别手工删掉控件行**，否则循环失效。
- 模板里样式 `Normal`（正文）带**首行缩进 2 字符**（`w:firstLineChars="200"`），所以页眉/页码等不缩进的元素都显式清零了缩进；你新增段落时若不想缩进，套用「顶格」样式。

## 1. `report-zh.docx` —— 通用中文报告

**用途**：实验报告 / 课程报告 / 结课论文这类「有标题、作者学号、摘要、若干章节、可能插图表」的中文报告。

**格式依据**（`SKILL.md` 第 2.1 / 2.2 节）：

- A4；页边距 上/下 2.54cm、左/右 3.17cm（左留装订线）
- 正文 `Normal`：宋体小四（12pt）、1.5 倍行距、首行缩进 2 字符
- 标题 `Heading 1`~`Heading 4`：黑体，字号递减 三号16 / 小三15 / 四号14 / 小四12，黑色
- 风格样式：`文档标题`（黑体小二居中）、`署名`、`图注`、`表注`（居中五号）、`表格文字`、`顶格`、`落款`
- 页眉（`{{ header }}`）+ 页脚居中页码（PAGE 域）
- 三线表：顶线 1.5pt、表头下线 0.75pt、底线 1.5pt，无竖线

**占位符清单**：

| 占位符 | 类型 | 说明 |
|---|---|---|
| `{{ title }}` | str | 报告标题（文档标题样式，居中黑体小二） |
| `{{ header }}` | str | 页眉文字 |
| `{{ author }}` | str | 作者 |
| `{{ student_id }}` | str | 学号 |
| `{{ date }}` | str | 日期 |
| `{{ abstract }}` | str | 摘要正文 |
| `{{ keywords }}` | str | 关键词 |
| `{{ body }}` | str | 「1 正文」下的正文 |
| `{{ table_caption }}` | str | 表题（渲染在表格上方，居中） |
| `rows` | list[dict] | 表格数据行；每个 dict 字段：`no` / `d` / `t` |
| `{{ table_note }}` | str | 表注（表格下方，居中） |
| `{{ image }}` | InlineImage | 插图；传 `InlineImage(tpl, "fig.png", width=Cm(11))` |
| `{{ figure_caption }}` | str | 图题（图下方，居中） |
| `{{ conclusion }}` | str | 「2 结论」下的正文 |

**怎么用**：

```python
from docxtpl import DocxTemplate, InlineImage
from docx.shared import Cm

tpl = DocxTemplate("templates/docx/report-zh.docx")
ctx = {
    "title": "落球法测黏度实验报告",
    "header": "物理实验报告",
    "author": "张三", "student_id": "2026001", "date": "2026-10-12",
    "abstract": "本文用落球法测量甘油黏度……",
    "keywords": "黏度；落球法；斯托克斯公式",
    "body": "……",
    "table_caption": "实验数据",
    "table_note": "注：d 为钢球直径，t 为下落时间。",
    "rows": [
        {"no": "1", "d": "1.98", "t": "8.42"},
        {"no": "2", "d": "1.97", "t": "8.51"},
    ],
    "image": InlineImage(tpl, "fig1.png", width=Cm(11)),   # InlineImage 必须用 tpl 构造
    "figure_caption": "实验装置示意",
    "conclusion": "……",
}
tpl.render(ctx)
tpl.save("报告.docx")
```

> `{{ image }}` 若上下文里不给，会渲染成空白（Jinja2 未定义变量按空串处理），不会报错。不插图就不传 `image`。

**必须人工收尾的地方**：插图 `image` 需自己准备好图片文件；页眉文字要按需改 `header`。

## 2. `gongwen-zh.docx` —— 党政机关公文（GB/T 9704—2012）

**用途**：通知 / 请示 / 报告 / 函等党政机关公文。版心、字体按国标预置。

**格式依据**（`SKILL.md` 第 2.5 节，GB/T 9704—2012）：

- 版心 **156×225mm**；天头(上) **37mm**、订口(左) **28mm**；下 35mm、右 26mm（由版心反推）
- 正文 `Normal`：**仿宋_GB2312 三号（16pt）**，固定行距 29pt（≈每页 22 行），首行缩进 2 字符
- 标题层级：一级 `Heading 1` **黑体**、二级 `Heading 2` **楷体_GB2312**、三/四级 `Heading 3/4` **仿宋_GB2312**（均三号）
- 页码：**4 号（14pt）半角宋体**、居中（见下方限制）
- 无页眉（公文格式不加页眉）

**占位符清单**：

| 占位符 | 类型 | 说明 |
|---|---|---|
| `{{ title }}` | str | 公文标题（`公文标题` 样式：二号、居中、加粗） |
| `{{ recipient }}` | str | 主送机关（`顶格` 样式，左顶格） |
| `{{ body }}` | str | 正文（仿宋三号、首行缩进 2 字符） |
| `{{ attachment_caption }}` | str | 附件说明 |
| `rows` | list[dict] | 表格数据行；字段：`no` / `item` / `note` |
| `{{ issuer }}` | str | 发文机关署名（`落款` 样式，右对齐） |
| `{{ date }}` | str | 成文日期（`落款` 样式，右对齐） |

**怎么用**：

```python
from docxtpl import DocxTemplate

tpl = DocxTemplate("templates/docx/gongwen-zh.docx")
ctx = {
    "title": "关于开展实验设备安全自查的通知",
    "recipient": "各学院、各实验中心：",
    "body": "为进一步加强实验室安全管理……（正文）",
    "attachment_caption": "实验设备安全自查表",
    "rows": [
        {"no": "1", "item": "高压设备", "note": "张贴警示标识"},
        {"no": "2", "item": "危化品柜", "note": "双人双锁"},
    ],
    "issuer": "XX大学",
    "date": "2026年10月12日",
}
tpl.render(ctx)
tpl.save("通知.docx")
```

**⚠️ 必须人工收尾 / 已知限制**：

- **`仿宋_GB2312` 缺失机器会回落** —— 公文正式交付请**转 PDF**，或先在自己机器勾「嵌入字体」另存。
- **标题用宋体加粗近似**：国标要求标题为**二号小标宋体**，该字体非通用，本模板用「宋体二号加粗」近似；正式发文请换成小标宋体。
- **页码规范未完全对齐**：GB/T 9704 要求**单页码居右空一字、双页码居左空一字**（奇偶页不同）。本模板简化为**居中**；若要严格合规，需在 Word 里加奇偶页页脚（`odd_and_even_pages_header_footer`）。
- **公文正文用「固定行距 29pt」** 来逼近每页 22 行；换字体或改字号后行数会变，请目检确认。
- **红头（发文机关标识）/ 印章是位图元素**，本模板不预置，需自行用现成红头模板。

## 3. `thesis-zh.docx` —— 学位论文（各校共性要求）

**用途**：本科/硕士毕业论文的**共性**格式骨架。各校细则不同，请以学校模板为准做微调。

**格式依据**（`SKILL.md` 第 2.6 节）：

- A4；页边距 上/下 2.54cm、左/右 3.17cm
- 正文 `Normal`：宋体小四（12pt）、1.5 倍行距、首行缩进 2 字符
- 标题 `Heading 1`~`Heading 4`：黑体，字号递减 三号16 / 小三15 / 四号14 / 小四12
- 页眉（`{{ header }}`）+ 页脚居中页码；**目录占位页**（真 TOC 域，按 F9 更新）
- 含封面区、摘要、目录、正文章节、三线表、参考文献占位

**占位符清单**：

| 占位符 | 类型 | 说明 |
|---|---|---|
| `{{ title }}` | str | 论文标题（文档标题样式） |
| `{{ header }}` | str | 页眉文字（常填「XX大学本科毕业论文」） |
| `{{ author }}` | str | 作者 |
| `{{ student_id }}` | str | 学号 |
| `{{ advisor }}` | str | 导师 |
| `{{ date }}` | str | 日期 |
| `{{ abstract }}` | str | 中文摘要 |
| `{{ keywords }}` | str | 关键词 |
| `{{ intro }}` | str | 「第 1 章 绪论」正文 |
| `{{ background }}` | str | 「1.1 研究背景」正文 |
| `{{ table_caption }}` | str | 表题 |
| `rows` | list[dict] | 表格数据行；字段：`no` / `item` / `value` |
| `{{ table_note }}` | str | 表注 |
| `{{ references }}` | str | 参考文献 |

**怎么用**：

```python
from docxtpl import DocxTemplate

tpl = DocxTemplate("templates/docx/thesis-zh.docx")
ctx = {
    "title": "基于 XX 的 XX 研究",
    "header": "XX大学本科毕业论文",
    "author": "李四", "student_id": "2026002", "advisor": "王教授", "date": "2026-10-12",
    "abstract": "……（中文摘要）",
    "keywords": "关键词1；关键词2",
    "intro": "……", "background": "……",
    "table_caption": "主要指标",
    "table_note": "数据来源：……",
    "rows": [{"no": "1", "item": "指标A", "value": "1.0"}],
    "references": "[1] 作者. 题名[D]. 城市: 学校, 年.",
}
tpl.render(ctx)
tpl.save("论文.docx")
```

**⚠️ 必须人工收尾 / 已知限制**：

- **目录要按 F9**：目录页是 TOC 域，`render` 后是空的占位说明；打开 Word 后把光标放进目录区按 **F9**（选「更新整个目录」）才生成。
- **各校细则不同**（字号、行距、奇偶页页眉、图表编号、参考文献格式 GB/T 7714 等）—— **优先拿学校官方模板**，本模板只保证共性骨架。
- **页码分节**（摘要用罗马数字、正文从 1 起）需分节实现，本模板为单节连续页码。
- 图表**交叉引用**、原生公式（OMML）本模板不含。

## 附：改这些模板

1. 想改参数（页边距、字号、行距、边框线宽）→ 改 `scripts/make_templates.py` 里对应的 `build_*` 函数与常量，重跑脚本。
2. 想加新模板 → 在脚本里加一个 `build_xxx(doc)`，注册进 `main()` 的 `builders` 列表。
3. 三线表的框线在 `three_line_table()` 里手写 XML（`w:sz` 单位是 1/8 pt）。**表格样式「三线表」无法表达「只在表头行下画细线」这种区域规则**，所以实际线条由生成时手写；样式本身只保证名字存在 + 默认无框线。
4. 生成后**务必**用 `python-docx` 重开验证 + 渲染目检（见 `SKILL.md` 第 3 节）。
